# JK Works Dordrecht app v39

Deze versie gebruikt weer een gewone Google Agenda-link in plaats van een .ics-bestand.

- Klussen en urenregistraties openen een vooringevulde Google Agenda-afspraak.
- Er wordt bewust geen specifieke agenda-ID meegestuurd. Google kiest dus zelf de standaard/laatst gebruikte agenda.
- Geen Apps Script, Google Cloud of extra Supabase-instellingen nodig.
- Handmatige Supabase-synchronisatie blijft behouden.
